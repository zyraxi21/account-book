## 导入导出功能（SAF + JSON/CSV）

为记账本应用加入整本账导入导出，通过系统文件选择器（SAF）完成，不申请存储权限、不联网。

### 新增文件
- `domain/BookSerialization.kt`：纯 Kotlin 的 JSON/CSV 编解码，无第三方依赖。金额在 JSON 中一律写字符串（避免二进制浮点漂移），读取端显式拒绝小数形式的 JSON 数字。
- `data/transfer/FileFormats.kt`：`ImportRequest`、`ExportFormat`（JSON/CSV 的扩展名与 MIME）、`readImportText`/`writeExportText`（5 MB 上限、剥 BOM）。
- `data/transfer/BookTransfer.kt`：导出入口，以及按扩展名 + 首字符判断格式、按表头分发 CSV 段落。
- `ui/components/FileTransferCard.kt`：设置页卡片，导出 JSON/CSV、导入、最近导出时间、进行中进度文案。
- `test/.../domain/BookSerializationTest.kt`：14 项编解码测试。

### 关键设计决定
- CSV 导出为三段（资产表、渠道表、收入表），每段带中文表头。表头固定为
  `月份,登记时间,渠道ID,渠道名称,余额,负债` / `渠道ID,渠道名称,启用,顺序` / `收入ID,项目,金额,日期时间,来源`。
- CSV 导入按**表头名称**解析（`CsvLayout`，含中英别名），支持列重排与省略可选列，位置仅作兜底。
- 合并语义：渠道/收入按稳定 ID 去重，已存在的月份跳过；替换语义：清空三表后整表重建。渠道先于资产插入（外键安全）。
- 空账本导入时不构造默认渠道，导入文件是唯一数据来源（沿用"不得静默销毁数据"的既有约定）。
- 导入是单个 `withTransaction`，失败不留半份数据；导入后重新断言隐私为隐藏。
- 导入导出在数据隐藏时禁用。
- Room 版本 1→2，`MIGRATION_1_2` 只加 `app_settings.lastExportAtMillis`，无破坏性迁移；schema `2.json` 手工按 1.json 派生（含 `identityHash` 重算）。

### 修复的两个真实产品缺陷
1. **负数金额被拒**：`Money.parse` 面向输入框，不接受负号，导致负债/净资产为负时往返失败。改为 `decodeMoney` 先校验定点写法、剥离符号按分换算、再还原符号（`Math.multiplyExact/addExact` 防溢出）。
2. **CSV 空行未跳过**：`parseCsvRecords` 对空行产生 `[""]` 而非空列表，原判据 `cells.isNotEmpty()` 失效，导致文件中间的空白行报 `IMPORT_MISSING_FIELD`。改为 `CsvRow.isBlank() = cells.all { it.isBlank() }`，同时保留空行行号以便提示与实际可见行号一致。
