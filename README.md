# 记账本

用一份月度对账单，记录资产变化与每一笔收入。

Android 本地记账应用：按月登记各渠道余额、负债与债权，记录收入，可从工商银行短信识别收入。账本加密保存在本机，不接入云同步，不上传任何账务数据。

当前版本 **2026.10.17.1**，[发布说明](release-notes/记账本%20v2026.10.17.1.md)。

## 功能

- **月度资产**：每个月保存一份资产表，包含各渠道余额、负债与债权，可补录、编辑和删除历史月份
- **收入明细**：按月份查看收入与累计收入，支持手动登记、编辑和删除
- **工行短信**：粘贴短信正文解析出项目、金额和日期；授权后自动识别新收到的工行收入短信
- **短信识别记录**：识别到的收入先进入待确认清单，核对后再入账、忽略或稍后处理；记录可按处理状态与银行卡尾号筛选
- **隐私保护**：顶栏一键隐藏账务，金额、项目、渠道名称和登记时间同时从画面与无障碍信息中移除
- **导入导出**：账本可导出为 JSON 或 CSV 保存到任意位置，也可从这两种格式恢复
- **检查更新**：启动时静默检查，关于页也提供手动检查，只在发现新版本时提示

## 使用

### 第一次打开

底部三个页面分别是资产、收入、设置。右上角的隐私按钮控制账务显示，默认隐藏，点一下即可查看和编辑。

### 登记每月资产

1. 在资产页切换到目标月份，点「登记资产」
2. 填写登记日期，逐个渠道输入余额，需要时填写负债与债权
3. 点「保存资产」；金额留空按 0 元保存

渠道可以自己添加、改名、删除，长按渠道名称可拖动排序。初始提供银行、支付宝、微信三个渠道。删除某个渠道后，历史月份仍保留当时的名称和余额。

### 记录收入

在收入页点「新增收入」，填写项目、金额和日期即可。收入必须大于 0，页面下方会按所选月份汇总本月收入与累计收入。

### 用短信自动记账

1. 在设置页打开「自动登记工行收入」，按提示授予短信权限
2. 应用在启动或回到前台时补查收件箱中来自 95588 的工行收入短信
3. 在收入页或设置页打开「短信识别记录」，核对待入账的记录，选择入账或忽略；记录页顶端显示上次补查结果，也可以随时点「补查」重新检查收件箱

识别到的收入不会直接计入账本，需要你确认。账本中已有同一天、同项目、同金额的收入时会自动跳过，不会重复入账。短信里的余额只用于校验，不会修改资产表。

不是每条短信都该记为收入：理财赎回、提现、银证转账这类到账会自动放进「已忽略」，不打扰你，需要时仍可手动入账。如果某张卡的短信完全不需要记录，可以直接在待确认弹窗里点「不导入尾号 xxxx」，也可以到设置页关掉这张卡，之后这张卡不再提醒。

不想授权短信权限时，也可以在收入页用「粘贴短信解析」手动完成同样的流程。

### 备份与恢复

设置页的「导入与导出」可以把整本账导出为 JSON（结构固定，适合备份和跨设备恢复）或 CSV（方便用表格软件查看）。导入时先选择方式：

- **合并**：只补齐本机缺少的渠道、收入和月份，重复导入同一份备份不会改动账本
- **覆盖**：删除现有账务后按文件重建，无法撤销，操作前会二次确认

导出的文件是明文，请自己妥善保管。

### 检查更新

关于页底部有「检查更新」，也可以在每次启动时自动检查。发现新版本时可选择稍后或立即下载，下载完成后调起系统安装器。

## 计算口径

| 指标 | 计算方式 |
| --- | --- |
| 总资产 | 各渠道余额合计 ＋ 债权 |
| 净资产 | 总资产 − 负债 |
| 与上月差额 | 本月与上月对比，可在设置页选择按净资产或按总资产 |
| 估算月支出 | 上月净资产 ＋ 本月收入 − 本月净资产 |

缺少相邻的上月资产表时，差额和估算月支出显示「暂无上月记录」。净资产、差额和估算月支出都可能为负数，估算值也会受投资涨跌、资产转入转出影响，仅供参考。

## 注意事项

- **数据只在本机**：账本与偏好加密保存，没有云同步。卸载应用或清除应用数据会一并删除账本和密钥，无法恢复，请定期导出备份
- **升级请覆盖安装**：保持相同的包名和签名直接覆盖安装，不要先卸载。卸载会丢失全部数据
- **金额规则**：金额最多两位小数；收入必须大于 0；渠道余额、负债、债权不能为负
- **短信权限**：读取和接收短信属于受限权限，需要安装器放行。澎湃 OS 还要在系统权限中额外允许「通知类短信」，否则可能查不到工行短信；开启自动登记后会弹出提示并可直接跳到对应设置。拒绝授权不影响手动登记和粘贴解析
- **隐藏状态下不能编辑**：账务隐藏时登记、编辑、删除按钮不可用，先点右上角的隐私按钮显示账务
- **短信识别的默认规则**：理财赎回、提现、银证转账默认记为忽略；项目名里全角半角标点、空格和大小写不同时仍视为同一笔，不会重复入账
- **短信只识别工行收入**：其他银行或其他类型的短信不会被识别

## 安装

从 [Releases](https://github.com/zyraxi21/account-book/releases) 下载最新的 APK 安装。仅支持 **arm64-v8a** 设备，最低要求 **Android 14**。

首次安装请在系统中允许「安装未知来源应用」。
