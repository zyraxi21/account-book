## 2026.10.08.1

本次更新修复渠道排序、余额输入光标和历史月份累计收入问题，完善资产登记界面，并新增启动时静默检查更新。

### 新增

- 启动时自动在后台检查更新，仅发现新版本时弹窗提醒；无更新或检查失败时保持静默，确认后才下载安装包
- 新增千位／万位分隔切换，默认使用千位分隔，偏好保存后下次启动继续生效
- 关于页增加作者 zyraxi、GPL v3 许可证和 GitHub 项目链接

### 界面改进

- 渠道管理集中到资产登记界面，支持卡片拖动排序、添加、改名和删除，移除设置页的重复入口
- 资产与月度差额合并展示，资产和收入使用编辑、删除图标；新增渠道改为通过按钮打开独立弹窗
- 统一深色模式下输入框、卡片、弹窗、Snackbar 和按钮的配色，关于页 Logo 随动态主题色变化
- 显示本月时禁用下一月按钮，返回“本月”的悬浮按钮增加出现和消失动画
- 关于页收紧排版，底部仅保留检查更新按钮；隐私提示统一使用“隐私按钮”表述

### 修复

- 修复渠道排序切换页面后恢复原状，以及排序未应用到资产登记的问题；拖动时相邻卡片会平滑让位
- 修复资产登记和编辑时每输入一位余额，光标就退回的问题
- 修复历史月份累计收入包含后续月份记录的问题，累计范围截止至所选月份月底
- 账务隐藏时直接禁用资产编辑和登记按钮，点击不再触发 Snackbar 提示
- 修复“本月”按钮过渡动画中阴影出现矩形边界，以及关于页检查更新按钮被裁切的问题
- 没有安装包时禁用下载按钮，下载期间可以取消

### 安装与升级

下载本页的 Release APK 安装，仅支持 **arm64-v8a**，最低要求 **Android 14**。

**已有用户请直接覆盖安装，不要卸载或清除应用数据。** 本次升级会保留账本、渠道和隐私偏好。卸载或清除数据会删除本机加密账本及密钥。

账务数据继续加密保存在本机，不接入云同步。千位／万位分隔只影响界面显示，金额输入及 JSON／CSV 文件仍使用无分隔符的精确数值。
